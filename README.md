# Voice Service 🎙️

A lightweight, high-reliability Text-to-Speech (TTS) microservice powered by Microsoft Edge's neural speech engine (unofficial, free) and Trafilatura web article extraction. Built with Python standard library HTTP server (`http.server.ThreadingHTTPServer`) and `edge-tts`.

### Role in the Broader Stack
- **Dedicated Neural TTS Engine**: Serves as the central speech synthesis provider for the entire stack.
- **Consumer: [`audio-briefing`](https://github.com/panospet/audio-briefing)**:
  - Synthesizes spoken Greek news segments from summaries pre-generated by `daily-news-aggregator`.
  - Synthesizes DJ-style music track intros ("Επόμενο κομμάτι: ...") announcing tracks pulled from `media-stack`'s Navidrome instance.
- **Consumer: [`daily-news-aggregator`](https://github.com/panospet/daily-news-aggregator)**:
  - Provides on-demand article narration directly from article URLs or plain text.
- **Host: [`media-stack`](https://github.com/panospet/media-stack)**:
  - Orchestrated and built as a container within `media-stack/docker-compose.yml`, using `network_mode: host` and bound to internal address `127.0.0.1:8002`.

## ✨ Features

- **High-Quality Neural Voices**: Native Greek neural voices (`el-GR-NestorasNeural` male, `el-GR-AthinaNeural` female) with adjustable rate, pitch, and volume.
- **Direct Text or URL Extraction**: Synthesize raw text, or provide an article URL to automatically extract title and cleaned article body via `trafilatura`.
- **SSRF Protection**: Strict URL validator ensures target hostnames resolve only to valid public IP addresses (blocking loopback, private RFC-1918, link-local, multicast, and broadcast addresses).
- **Intelligent Text Chunking**: Splits long texts into chunks (<= 1,000 characters) respecting sentence boundaries (`.`, `!`, `?`, `;`, `…`, newlines) to prevent synthesis timeouts.
- **Exponential Backoff & Resilience**: Retries dropped or empty chunk responses up to 3 times with exponential backoff (1s, 2s).
- **Content-Addressable Disk Cache**: Synthesized MP3s are cached on disk (`CACHE_DIR`) keyed by SHA-256 (`hash(text, voice, rate, pitch, volume)`). Repeated requests and retries return in ~0ms without hitting external network endpoints.
- **Automated Retention Management**: Periodic hourly scan prunes cached MP3 files exceeding `CACHE_RETENTION_DAYS` (default 30 days).
- **Zero Heavy Web Frameworks**: Implemented directly using Python's standard library `ThreadingHTTPServer` for minimal resource consumption.
- **Security & Auth**: Enforces HTTP Basic Authentication (`AUTH_USERNAME` / `AUTH_PASSWORD`) with constant-time comparison to prevent timing attacks.

## 🔌 API Reference

### 1. Health Check
```http
GET /healthz
```
**Response (200 OK):**
```json
{"ok": true}
```

### 2. Synthesize Speech
```http
POST /synthesize
Authorization: Basic <base64(AUTH_USERNAME:AUTH_PASSWORD)>
Content-Type: application/json
```

#### Request Payload: Direct Text
```json
{
  "type": "text",
  "text": "Καλημέρα σας. Αυτές είναι οι σημαντικότερες ειδήσεις της ημέρας.",
  "voice": "el-GR-NestorasNeural",
  "rate": "+0%",
  "pitch": "+0Hz",
  "volume": "+0%"
}
```

#### Request Payload: Web Article via URL
```json
{
  "type": "url",
  "url": "https://www.example.com/article-slug",
  "voice": "el-GR-AthinaNeural"
}
```

#### Parameters:
| Field | Type | Required | Default | Description |
|---|---|---|---|---|
| `type` | string | **Yes** | — | Either `"text"` or `"url"` |
| `text` | string | When `type="text"` | — | Plain text to synthesize (max 20,000 chars) |
| `url` | string | When `type="url"` | — | Public HTTP/HTTPS URL of article to extract & read |
| `voice` | string | No | `TTS_VOICE` (`el-GR-NestorasNeural`) | Edge TTS voice ID (e.g., `el-GR-AthinaNeural`) |
| `rate` | string | No | `TTS_RATE` (`+0%`) | Speed adjustment (e.g., `+10%`, `-5%`) |
| `pitch` | string | No | `TTS_PITCH` (`+0Hz`) | Pitch adjustment (e.g., `+5Hz`, `-5Hz`) |
| `volume` | string | No | `TTS_VOLUME` (`+0%`) | Volume adjustment (e.g., `+0%`, `-10%`) |

#### Response:
- **`200 OK`**: Binary audio stream (`Content-Type: audio/mpeg`, 24 kHz MP3).
- **`400 Bad Request`**: Invalid input, missing parameters, or private URL detected (`Content-Type: application/json`).
- **`401 Unauthorized`**: Missing or invalid HTTP Basic authentication.
- **`413 Payload Too Large`**: Request body exceeds 64 KB.
- **`500 Internal Server Error`**: TTS generation failed.

#### Example `curl`:
```bash
curl -u "user:pass" \
  -X POST http://127.0.0.1:8002/synthesize \
  -H "Content-Type: application/json" \
  -d '{"type":"text","text":"Δοκιμαστική αναπαραγωγή."}' \
  --output test.mp3
```

## ⚙️ Configuration & Environment Variables

| Variable | Default | Description |
|---|---|---|
| `VOICE_BIND` | `127.0.0.1` | Network interface IP to bind |
| `VOICE_PORT` | `8002` | Port to listen on |
| `AUTH_USERNAME` | *(required)* | HTTP Basic authentication username |
| `AUTH_PASSWORD` | *(required)* | HTTP Basic authentication password |
| `ALLOW_UNAUTHENTICATED` | `false` | Set to `true` to disable authentication (not recommended) |
| `TTS_VOICE` | `el-GR-NestorasNeural` | Default voice identifier |
| `TTS_RATE` | `+0%` | Default speech rate |
| `TTS_PITCH` | `+0Hz` | Default voice pitch |
| `TTS_VOLUME` | `+0%` | Default voice volume |
| `CACHE_DIR` | `/tmp/voice-cache` | Directory path for storing synthesized MP3 audio cache |
| `CACHE_RETENTION_DAYS`| `30` | Number of days to retain cached MP3 files before pruning |

## 🚀 Deployment

### Option A: Via `media-stack` (Recommended)
This service is integrated directly into the `media-stack` compose setup:
```yaml
# In media-stack/docker-compose.yml:
voice-service:
  build:
    context: ../voice-service
  container_name: voice-service
  user: "1000:1000"
  network_mode: host
  restart: unless-stopped
  environment:
    - TZ=Europe/Athens
    - VOICE_BIND=127.0.0.1
    - VOICE_PORT=8002
    - TTS_VOICE=el-GR-NestorasNeural
    - CACHE_DIR=/app/cache
    - AUTH_USERNAME=${AUTH_USERNAME}
    - AUTH_PASSWORD=${AUTH_PASSWORD}
  volumes:
    - ${BASE_DIR}/voice-cache:/app/cache
```

Start via `media-stack`:
```bash
cd ~/media-stack
docker compose up -d voice-service
```

### Option B: Standalone Docker
```bash
docker build -t voice-service .
docker run -d \
  --name voice-service \
  --network host \
  -e AUTH_USERNAME=myuser \
  -e AUTH_PASSWORD=mypass \
  -e CACHE_DIR=/data/cache \
  -v /var/cache/voice:/data/cache \
  voice-service
```

### Option C: Local Development
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

export AUTH_USERNAME="devuser"
export AUTH_PASSWORD="devpassword"
python3 app.py
```
